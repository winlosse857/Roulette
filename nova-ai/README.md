# NOVA AI — подключение Claude

## Что понадобится
- Node.js 20 или новее.
- API-ключ Anthropic Claude.
- Доступ к Claude API и доступная квота/оплата в Anthropic Console.

## Запуск локально
1. Создай копию `.env.example` с именем `.env`.
2. Вставь ключ только в `.env`.
3. В терминале этой папки выполни `npm start`.
4. Открой `http://localhost:3000`.

## Безопасность
- Не вставляй API-ключ в `public/index.html`, JavaScript браузера, GitHub или публичные сообщения.
- Не загружай `.env` в репозиторий. Он добавлен в `.gitignore`.
- Для публикации добавь `ANTHROPIC_API_KEY` в секретные переменные окружения хостинга.
- Перед публичным запуском добавь авторизацию, более строгие лимиты, мониторинг расходов и защиту от злоупотреблений. Текущий лимит в памяти — только базовая защита прототипа.
- API-запросы могут тарифицироваться Anthropic.

## Настройки
По умолчанию используется `claude-sonnet-5-5`. Если у ключа нет доступа к этой модели, укажи доступный ID в `ANTHROPIC_MODEL`.

История хранится только в памяти вкладки и исчезает после перезагрузки. Браузер обращается к `/api/chat`, а сервер вызывает Anthropic Messages API; ключ не отправляется в браузер.
